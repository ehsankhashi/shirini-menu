# سرور سفارش‌های شیرینی‌سرا

## راه‌اندازی
1. در «بله» با @botfather یک ربات بسازید و توکن را بگیرید. (اگر سرور خارج از ایران است می‌توانید ربات تلگرام و `BOT_API=https://api.telegram.org` بگذارید.)
2. ربات را به چت خودتان یا یک گروه اضافه کنید و `chat id` آن را بردارید (در گروه، ربات باید عضو باشد).
3. اجرا (Node 18+):

```bash
BOT_TOKEN=xxxx OWNER_CHAT_ID=123456 ALLOWED_ORIGIN=https://your-site.ir node server.js
```

پیامک به مشتری (اختیاری): `KAVENEGAR_KEY=...` و در صورت نیاز `KAVENEGAR_SENDER=...`

4. در `script.js` مقدار `ORDER_API` را برابر آدرس سرور بگذارید، مثلاً `"https://order.your-site.ir"`.
   (برای جلوگیری از خطای mixed-content، آدرس سرور باید https باشد.)

## نحوه‌ی کار
- مشتری «ثبت سفارش» را می‌زند ← سفارش با دکمه‌های «تأیید / لغو» در بله/تلگرام برای شما می‌آید.
- با «✅ تأیید و شروع آماده‌سازی»، وضعیت سفارش می‌شود «در حال آماده‌سازی».
  مشتری این را (۱) در سایت به‌صورت پیام بالای صفحه و در «حساب من ← سوابق سفارش» و (۲) در صورت تنظیم، با پیامک می‌بیند.
- بعد از آن دکمه‌ی «🎉 تحویل شد» برای بستن سفارش هست.

## نکته‌ها
- برای ماندگاری، `orders.json` را بکاپ بگیرید و سرور را با pm2 یا systemd اجرا کنید.
- مبلغ‌ها از سایت می‌آیند؛ هنگام تأیید، مبلغ را در پیام ربات بررسی کنید.
